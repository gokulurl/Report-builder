Developer notes

Access
MY REPORTS shows in a module when the user can access that module; it lists that module’s templates and the user’s own reports. REPORT BUILDER needs the IT permission; IT also use MY REPORTS by switching module. Restricted columns, export and scheduling follow existing HMS permissions.
Shell and content styles
Shell: Roboto, #0065CB, #FE6300, #F4F7FF, unchanged. Content: the new UI in DM Sans only (Gilroy is off), from the Design System tokens. Scope the new CSS under the page wrapper so nothing leaks into the shell.
Icons
Content icons are Heroicons outline drawn as CSS masks (src/styles/_hero-icons.scss, generated by tools/gen-hero-icons.mjs). Shell icons are Fusion’s own assets/svg; the two new rail icons are in public/fusion/.
Where it lives in the repo
src/app/fusion-nav.ts the rails · src/app/app.html a shell replica (don’t ship it) · src/app/fusion-screen.ts stand-ins · src/app/rb/* the screens to build · src/new-ui.scss the styles.
