BuildNotes for developers

Access

  • MY REPORTS shows in a module when the user can access that module. It lists that module's templates and the user's own reports.
  • REPORT BUILDER needs the IT permission. IT also use MY REPORTS, by switching to the module.
  • Restricted columns, export and scheduling follow existing HMS permissions.

Two design systems side by side

  • Shell: Roboto, #0065cb, #fe6300, #f4f7ff. Unchanged.
  • Content: the new UI (DM Sans, v2 tokens). Scope its CSS under the page wrapper so nothing leaks into the shell. The prototype loads it globally.
  • New rail icons: public/fusion/my-reports.svg and report-builder.svg, 24px, #352C49, turned white when active. Swap in official ones if design has them.

Where it lives in the prototype

  • src/app/fusion-nav.ts: the two rails, with the added items marked.
  • src/app/app.html, app.scss: a replica of the shell, measured off qa. Don't ship it; the product keeps its own.
  • src/app/fusion-screen.ts: stand-ins for existing screens, so the walk can be clicked.
  • src/app/rb/*: the new screens to build.
